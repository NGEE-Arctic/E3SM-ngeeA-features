# E3SM-ngeeA-features
Documents and data specifically developed for E3SM (Land Model, aka ELM) in NGEE-Arctic Project.


## Features, Data and/or Parameters for pan-Arctic ELM
- ***Features***: definition, functionality, critical algorithms (or code changes)
- ***ELM options***: namelists or flags for using those Features
- ***Data or Parameters***: required or optional data, parameters, including versioning for those Features
